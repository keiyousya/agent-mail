日医標準レセプトソフトORCAと連携するシステムとして開発を進めている。

- 医療機関等ONS（vendorons.service-now.com）にベンダー登録済み
- 2026-07-27: ONSポータルのアカウントがロックされ、サービスデスクに解除依頼済み
- 2026-07-27: オンライン資格確認・電子処方箋の検証環境の利用申請方法を問い合わせ済み（vendorons@service-now.com宛）
- 2026-07-27: ORCA管理機構にテスト環境の利用を問い合わせ済み（info@orca.med.or.jp宛）
- 日医IT認定事業所の取得に向けて準備中（JSMA医科医療事務管理士の受験要件は確認済み）
- ORCA管理機構 廣瀬氏（nintei@orcamo.co.jp）とのやり取り実績あり

**Why:** 診療支援システム開発にはORCA連携・オンライン資格確認・電子処方箋との連携が必要なため、検証環境が必須。

**How to apply:** 医療関連の問い合わせやシステム開発の文脈で参照する。
