勾当台夕方内科クリニックのベースアップ評価料（外来・在宅ベースアップ評価料）に係る
令和8年度「賃金改善中間報告書」は、**東北厚生局へ提出済み**（2026-09-13に田村さんが提出済みと明言）。
本案件はクローズ。次の提出は令和9年8月の令和8年度「実績報告書」。

## 提出物は「中間報告書」のみ

クリニックは2026年4月開院、届出は2026年5月25日、算定開始は6月分から。
つまり**令和8年6月以降にはじめて算定する保険医療機関**にあたるため、
提出は令和8年度「**賃金改善中間報告書**」の1本のみ。
令和7年度の実績報告書は提出不要（令和8年度分の実績報告書は令和9年8月に提出）。

- 報告対象期間は**令和8年6月・7月の2か月分**のみ（東北厚生局が明示）
- 様式は「R8実績・中間報告書（病院・診療所用）」。**令和8年7月30日に更新**されており、
  比較基準月を切り替えるチェック欄が追加されている。必ず最新版を使う
- Excel内の「別添2」（届出事項は「報告書提出」を選択）と「様式100別添1」の2シートに記入
- 提出は東北厚生局の宮城県用の専用アドレスへExcelのままメール添付（届出時と同じ宛先）。
  PDF・Zip・スプレッドシート・加工Excel・パスワード付き・共有リンクはすべて不可
- ファイル名は `医療機関コード_令和8年度ベースアップ評価料賃金改善中間報告書.xlsx`
- 中間報告書は「賃金改善額充当不足」と表示されても提出可能

## 開院1年目でも作成できる

賃金改善「前」の基本給等総額は実在の前年度実績ではなく、
**令和8年5月時点の給与体系に、6月と同じ年齢・職位の職員が在籍していたと仮定した額**を書く。
4月開院でも5月の給与体系は存在するので問題なく作成できる。
（令和8年4月からの賃金改善に充当している場合のみ3月基準になるが、開院前なので該当しない）
