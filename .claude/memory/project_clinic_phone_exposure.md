勾当台夕方内科クリニックの携帯番号（開設時の代表番号）がファストドクター等の
医療機関ポータルに掲載されている。2026-09-12に出どころを特定した。

## 出どころ：東北厚生局「コード内容別医療機関一覧表」

毎月公表されるPDF/Excelに**電話番号の列がある**。宮城県・医科版（令和8年9月1日現在）の
項番992、医療機関コード 0415119874 に携帯番号が載っている。誰でもDLできるため、
医療機関DBを作る業者の一次ソースになっている。
https://kouseikyoku.mhlw.go.jp/tohoku/gyomu/gyomu/hoken_kikan/itiran.html

ファストドクターの掲載もこれが出典とみてよい。住所の全角表記が厚生局PDFと一致し、
診療科が「内科」のみ、診療時間が空欄（厚生局の一覧に診療時間欄がない）。
自院サイトには固定番号を載せているので、サイトから拾ったものではない。

## 潰した可能性

- **医療情報ネット（ナビイ）のe-Govオープンデータ**：診療所の施設情報CSV全62列を確認したが
  **電話番号の列はない**。一括配布経路はこちらではない（画面上には表示される）。
- **ドメインのWHOIS**：代理公開済み。漏れていない。

## 変更手続きの壁

電話番号は**どちらの変更届様式にも欄がない**。様式を開いて全項目を確認した結果：

- 厚生局「保険医療機関・保険薬局届出事項変更（異動）届」：電話番号欄なし。
  「その他の変更」は区画・診療科目・診療時間・病床数減・法人所在地等まで。
- 仙台市 様式第10-1号「診療所開設届出事項変更届出書」：「4 変更した事項」(1)〜(17)に
  電話番号なし＝医療法施行令第4条第3項の法定変更事項ではない。

一方、**医療機能情報提供制度では明確に報告事項**（宮城県のページに「病院等の案内用の
電話番号及びファクシミリの番号」と明記）。紙の「変更報告書」様式もあり、提出先は管轄の保健所。

## G-MISの状態

医療機関マスタに携帯番号が入っているが**閲覧のみで編集不可**。
随時報告のメニューがG-MIS・医療情報ネットのどちらにも表示されない
（調査メニューは年次/日次週次/緊急配布/病床機能/外来機能/特例水準/各種調査の7つのみ、
医療情報ネットの関係者メニューは検索とパスワード変更のみ）。
アカウントに報告権限が付いていない可能性が高く、これをG-MIS事務局に照会中。

## 2026-09-14 G-MISの回答と新規報告の着手

G-MIS事務局の回答：医療情報ネットの案内用電話番号は、医療機能情報提供制度の**新規報告**で入力する
（G-MISホーム→緑の「医療機能情報提供制度」→「新規報告」→【1.(1)基本情報】の案内用電話番号）。
この日ログインするとメニューが表示され、**当院は同制度の報告を一度もしていない**ことが判明。
電話番号だけの変更手続きはなく、全30画面の新規報告を作る必要がある。報告→県確認→約4時間で医療情報ネットに掲載。

- 画面冒頭で「先にかかりつけ医機能報告取込を実行」と指示される（◆印の画面が取込対象）
- 入力画面の癖：電話は `(022)393-8689` 形式、時刻は `hhmm`（1700）。一部の入力は親画面を一時保存すると解放される
- 2026-09-14に一時保存済み：1.(1)基本情報（開設日だけ未入力）、診療科目（内科）、診療時間、1.(2)アクセス（時間外対応は未入力）
- 同日、開設日2026/02/17・予約一部実施・時間外（加算3届出）・院内サービス（院内外処方併用、翻訳機、筆談、バリアフリーなし、全面禁煙、相談員なし）も一時保存
- 「かかりつけ医機能報告取込」は「取込可能なデータがありません」で失敗。かかりつけ医機能報告（2025年度定期報告）は報告状況「報告中」で、報告日・確認完了日が空欄（未提出の可能性）
- かかりつけ医機能報告の2025年度分は、マニュアル（R7.11）「報告期間中に新規開設された医療機関は次年度から報告対象」により**提出不要と判断**（田村さんがA案を選択、2026-09-14）。初回は2026年度分（2027年1〜3月、実績は2026年4月〜2027年3月）。医療機能情報の◆画面は取込せず手入力する
- 2026-09-14 13:55時点で一時保存済み：1.(1)〜(2)、1.(3)院内サービス、1.(4)費用負担2画面、2.(1)診療内容・設備・併設介護施設・専門外来・在宅医療・かかりつけ医機能、3.実績。未入力：外国人受入れ（言語）、専門性資格、疾患・治療、健診、人間ドック、予防接種、人員配置、難病
- G-MIS入力の技術メモ：ボタン型の選択肢は `fieldset > legend` と `label` をJSでクリック可。チェックボックスは lightning-input の shadowRoot 内の input を click。確認ダイアログのOKはJSで取れないので座標クリック。保存直後のクリックは取りこぼすので数秒待つ
- 厚生局の回答は「県別の疑義照会フォームから出し直せ」だった（仙台市は未回答）

**Why:** 元データを直さないと、消しても別の業者がまた載せる。手続きの正式ルートが
様式上に存在しないため、窓口に確認しないと進められない。

**How to apply:** 回答が来たら、厚生局→仙台市→G-MISの順に登録番号を固定番号へ差し替える。
一覧表は毎月1日現在で更新されるので、月内に片付けば翌月版から消える。
元が直ったあとで各ポータルに修正依頼を出す。番号そのものは [[project-clinic-phone]] を参照。
窓口のメール経路は [[reference-agency-inquiry-channels]]。
