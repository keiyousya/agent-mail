勾当台夕方内科クリニックは **2026年8月26日から約3週間**（9月中旬頃まで）休診となり、
その間は田村さんが不在になる。

## スケジュールへの影響

- **8月中に片付けるべきもの**は8月25日までに終わらせる必要がある
  - [[project_baseup_report]] のベースアップ評価料 中間報告書（8月中提出）
- **業者の来院を伴う作業**は8月中旬までに寄せる
  - 労災レセプトオンライン請求の設定作業（アルファシステム）は
    9月導入で進めつつ、作業日を8月中旬までにお願いする方針で返信済み
- 9月上旬にレスポンスを期待する予定は組まない

**Why:** 8月末〜9月中旬は連絡・対応ができないため、期限もののスケジュールが前倒しになる。

**How to apply:** 日程調整や期限のある案件が出たら、8月25日という区切りを前提に逆算する。
先方への連絡文では休診の理由には触れず「休診とさせていただく予定」とだけ書く。
