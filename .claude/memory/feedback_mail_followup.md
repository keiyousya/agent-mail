メールチェック（[[feedback_draft_not_send]] の check-mail スキル）で「要対応」として挙げた項目は、
田村さんがすでに自分で片付け済みであることが多い。督促メール・通知メールの文面だけを根拠に
「未対応」と判定しない。

2026-09-13のメールチェックでの実例:

- UPSIDERの「【要対応】本人確認手続きにおける必要書類のご案内」（9/8再送・9/10）は、
  リンクを開いたら「取引時確認を受け付けました」の完了画面だった。督促メール自体に
  「すでにお手続き済みの場合はご放念ください」と書かれており、単なる行き違いだった
- ベースアップ評価料の中間報告書（[[project_baseup_report]]）も提出済みだった
- 残りの要対応項目（税理士の請求書・カードの振込金額・ORCAカンファレンス・
  GitHub Actions無料枠・医療情報ネットのパスワード設定）も、すべて確認済みとのことだった

**Why:** 対応済みの件を「未対応」として並べると、田村さんに不要な確認作業をさせることになる。
督促メールは行き違いで届くのが常で、メール本文は状況の証拠にならない。

**How to apply:** 要対応として挙げるときは「未対応です」と断定せず、
「行き違いでなければ」「未対応であれば」と留保を付けるか、
リンクを開いて実際の状態を確かめてから報告する。
報告後に「対応済み」と言われたら、関連するプロジェクトメモリの状態も更新する。
