ユーザーの指示に基づいてGoogleカレンダーに予定を登録してください。

## ルール

- 必ず「家族」カレンダー（ID: `family08116150111335324801@group.calendar.google.com`）に登録すること
- タイムゾーンは `Asia/Tokyo` を指定すること
- 時間が不明な場合は終日イベントとして登録すること
- 場所が分かっている場合は location に設定すること
- 関連URLや補足情報があれば description に含めること

## 手順

1. ユーザーの指示から、イベント名・日時・場所・詳細を抽出する
2. 不足情報があればユーザーに確認する
3. `create_event` で家族カレンダーに登録する
4. 登録結果を報告する
